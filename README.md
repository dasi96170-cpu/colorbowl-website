# 彩碗網站 GitHub 部署版

這個資料夾只保留網站公開上線需要的內容，可直接部署到 GitHub Pages。

## GitHub Pages 設定

1. 將此資料夾內的全部內容上傳到 GitHub 儲存庫的 `main` 分支。
2. 前往儲存庫的 `Settings` > `Pages`。
3. 在 `Build and deployment` 選擇 `Deploy from a branch`。
4. Branch 選擇 `main`，資料夾選擇 `/(root)`，然後儲存。

首頁入口為 `index.html`。

## 後續更新

網站內容修改完成後，重新同步正式頁面與資源，再推送到 GitHub。
